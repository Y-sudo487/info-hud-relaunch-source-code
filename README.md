First: The Relaunch Name Is Because I Made A Mod Like This In 2025, But Deleted It Due To Many Issues. (If You're Wondering, The Mod Name Was Info Hud++)

Second: The Idea For This Mod Came From A Friend Of Mine.

Third: Current Mod Features Are (As Of Beta 0.0.5):

(1) The Ability To Adjust Visibility Of The Hud Using A Set Keybind (H).

(2) The Ability To Edit The Hud By Opening The Edit Screen Using (G).

(3) The Ability To Adjust Colors.

(4) The Ability To Adjust Y Position.

(5) The Ability To Adjust Drop Shadow Of Text.

Fourth: Current Known Bugs Are:

(1) When Hitbox (F3+B) Or Chunk Borders Is Shown, The Hud Is Invisible. Issue Is Fixed As Of Beta 0.0.4. Affected Versions: Beta 0.0.1, Beta 0.0.2, Beta 0.0.3.

(2) Some Ui Scales Or Low Display Resolutions May Make Edit Screen Buttons Go Off Screen. Affected Versions: Beta 0.0.1, Beta 0.0.2, Beta 0.0.3, Beta 0.0.4, Beta 0.0.5.

(3) Some Text Colors In The Edit Screen Are Colored Incorrectly. Issue Is Fixed As Of Beta 0.0.4. Affected Versions: Beta 0.0.1, Beta 0.0.2, Beta 0.0.3.

(4) Text For The Reset Drop Shadow Button Doesn't Fit Its Button. When Clicked, Fps Drop Shadow Will Be Set To False, But The Text Will Still Be "On". Affected Version: Beta 0.0.5.
